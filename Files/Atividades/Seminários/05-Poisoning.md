# Poisoning Attacks em LLMs - 30/10/2025

## O que é envenenamento de dados

- Adição de dados maliciosos que manipulam o comportamento do modelo.

## Exemplo de Modelos envenenados

- Eles podem botar um trigger como um quadradinho vermelho, ou um gradiente escondido nos pixels
- Com 300 imagens já destruiu o modelo

## Como é um ataque por envenenamento em LLM?

## Riscos desse tipo de ataque

- Data dumping
- Recomendações maliciosas
- Propaganda ideológica/política
- Manipulação dos fatos
- Negação de recursos

## Questões do trabalho

- Quantos exemplos envenenados são necessários?
- Aumentar a escala do modelo influencia na quantidade de imagens?

## Experimentos

### Experimento 1

- A proporção não é relevante, mas a quantidade absoluta sim.

## Why are LLMs vulnerables?

- Eficiência amostral
- Padrão não diluído
- Backdoor simles
- Difíceis de detectar
- Dados não confiáveis é inerente ao processo

## Contramedidas

- Dados limpos
- Foco em segurança
- Detecção de Backdoors
- Ordenação dos dados
- Ajuste de hiperparâmetros
